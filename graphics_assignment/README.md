# Computer Graphics Assignment

This folder contains Python implementations of classic computer graphics algorithms:

- Bresenham line drawing
- Midpoint circle drawing
- Scanline polygon fill with simple shading
- Koch curve fractal
- 2D transformations (translation, rotation, scaling)

## Run

```powershell
python graphics_assignment\graphics_algorithms.py
```

## Output

PNG files are generated in:

`graphics_assignment\output_images`
